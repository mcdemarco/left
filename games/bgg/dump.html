Data Dump Sorter

Sort the data dump in order by ascending image and return the top games, including expansions, omitting bad values.1

Before sorting, restrict the data dump to only: geek ratings between and ranks between and average ratings between and base games name between and year published between and expansions2 ids between and number of votes between and

If you omit one value from a range, that end of the range will be unrestricted. Note that in some cases, there is a difference between a low value of 0 and an unrestricted range (which may include bad values1). The bad year 0 will be omitted if it falls within the year published range, but not if it falls in an unrestricted range.
