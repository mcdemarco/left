My interest in dominoes started with [Euronimoes](https://boardgameforge.wordpress.com/euronimoes/), or possibly with [Kingdomino](https://boardgamegeek.com/boardgame/204583/kingdomino).  I've also played some interesting solitaires:  [13 Black Cats](https://boardgamegeek.com/boardgame/130716/13-black-cats) and [Domino Runners](https://www.abstractgames.org/dominorunners.html).

So far, my only domino game is [Hegemino](/games/domino/hegemino/), though it was inspired by my dominoes-like Decktet game [Personimo](/games/decktet/personimo/).
